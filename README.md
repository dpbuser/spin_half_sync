This repository contains the code used to generate the numerical results of the paper "NAME." In order to run these scripts, the following packages must be installed: numpy, scipy, qutip, numba, matplotlib. It is recommended that one starts with sync_tester.py first as one can verify the basic results of the paper such as the steady states of Eq. 4 converging to the state |NS,K><NS,K| as well as verify the negativity of these states. After this, one can either go to the husimi_Q_funcs.py or geodesic_dist.py scripts and reproduce Figs. 1 and 3 and verify these results. Note that geodesic_dist.py takes some time to run depending on the step size of the input l values at which you calculate g(l) due to the triple integral. Finally, one can reproduce the oscillation revival plots of Fig. 4. One can verify the claims made that all spins effectively having the same observed frequency.
